# SauceDemo Manual Testing Project

## Project Overview

This project demonstrates manual testing of the SauceDemo e-commerce web application.

The project covers requirement analysis, test scenario design, test case design, test data preparation, test execution, test design techniques, exploratory testing, and requirement traceability.

## Application Under Test

- Application: SauceDemo
- Application Type: E-commerce Web Application
- Testing Type: Manual Testing

## Modules Tested

- Login
- Products
- Cart
- Checkout
- Logout

## Testing Activities

- Requirement Analysis
- Test Scenario Design
- Test Case Design
- Positive and Negative Testing
- Equivalence Partitioning
- Decision Table Testing
- Error Guessing
- Exploratory Testing
- Test Data Preparation
- Test Execution
- Requirement Traceability Matrix (RTM)
